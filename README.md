# Mouse Control for IO Nova SE

> **Неофициальная легковесная утилита управления для беспроводной игровой мыши IO by Red Square Nova SE.**  
> *Lightweight unofficial control suite for IO by Red Square Nova SE gaming mouse.*

---

## Возможности (Features)

- **Мониторинг батареи в реальном времени:**
  - Точный процент заряда без задержек и подвисаний.
  - Динамический расчёт оставшегося времени автономной работы (при частоте опроса 1000 Гц).
  - Уведомления о разряде и звуковые сигналы для игр в полноэкранном режиме.
  - Оповещение о 100% зарядке (провод можно снять).
- **Программный анти-даблклик (Eager Debounce Filter):**
  - Мгновенная регистрация первого клика (0 мс задержки в шутерах).
  - Подавление остаточного дребезга контактов микрика (настраиваемый порог 5–40 мс).
- **Одометр и счётчик ресурса переключателей (Huano 80M):**
  - Подсчёт физических нажатий ЛКМ и ПКМ за всё время и за текущую сессию.
  - Расчёт износа ресурса микропереключателей Huano Blue Shell Pink Dot (80 000 000 кликов).
  - Атомарное сохранение в память с пакетной записью на диск для защиты SSD.
- **Аппаратный автокликер:**
  - Настраиваемая скорость от 1 до 60 CPS.
  - Режимы удержания (Hold) и переключателя (Toggle).
  - Модуль хуманизации (микро-джиттер задержки против античитов).
  - Привязка на любую клавишу клавиатуры.
- **Интеграция с Windows:**
  - Системный трей с динамической иконкой состояния батареи.
  - Тёмная (Dark Precision) и светлая (Warm Minimalist) темы оформления.
  - Чистый инсталлятор с автоматическим закрытием процессов и деинсталляцией через «Параметры Windows».
  - 0% нагрузки на CPU в фоновом режиме, отсутствие статтеров на 1000 Гц.

## Установка (Installation)

1. Скачайте инсталлятор **`MouseControl_Setup.exe`** из раздела [Releases](../../releases).
2. Запустите установку. Инсталлятор автоматически настроит ярлыки и (опционально) автозапуск.
3. Либо скачайте портативную версию `MouseControl.exe` из релизов и запускайте без установки.

## Архитектура и технологии (Tech Stack)

- **Платформа:** .NET 6 (WPF, C#)
- **Целевая архитектура:** `win-x86` (для полной совместимости с 32-битным HID-драйвером)
- **Взаимодействие с железом:** SetupAPI (`setupapi.dll`), Windows HID (`hid.dll`), Win32 Low-Level Hooks (`WH_MOUSE_LL`, `WH_KEYBOARD_LL`)
- **Оптимизация:** Выделенные потоки с приоритетом `Highest`, sub-nanosecond fast-path для обработки событий 1000 Гц без лагов курсора.

## Сборка из исходников (Building from Source)

Требования:
- [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0)
- Inno Setup 6 (для сборки инсталлятора, опционально)

```bash
# Клонировать репозиторий
git clone https://github.com/<username>/nova-se-control.git
cd nova-se-control

# Сборка проекта
dotnet build MouseControl -c Release

# Публикация единого exe-файла
dotnet publish MouseControl\MouseControl.csproj -c Release -r win-x86 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o MouseControl\bin\Publish
```
